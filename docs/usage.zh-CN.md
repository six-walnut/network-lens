# 网络透镜 · Network Lens

一个使用 Swift + SwiftUI/AppKit 构建的 macOS 本地网络监测桌面组件。

## 1.1 紧凑版

桌面组件已精简为 **190 × 190 pt 正方形**，宽度为原来的一半。主界面仅显示状态、网关/DNS/外网/网站结果与更新时间。右上角省略号菜单打开设置、历史和导出；右下角“详情”展开完整诊断及趋势。窗口没有标题栏，拖动空白区域移动；菜单栏仍可重新显示组件。

## 开始使用

1. 下载 Release 安装包并解压，双击 **NetworkLens.app**。已在本机编译并使用本地 ad-hoc 签名。
2. 组件可以拖动，常驻菜单栏；关闭组件窗口不退出检测。菜单栏中可重新显示或退出。
3. 点击右上角省略号菜单中的“设置”，配置公司系统/经常故障的网站，选择间隔、深浅色、透明度或悬浮置顶。
4. 默认自动探测，每 5 秒开始一轮；探测较慢时等待当前轮完成，不叠加常规轮次。
5. 如 macOS 询问本地网络访问，此权限用于本地网关和内网站点检测。未允许时网关结果可能受限。

这是**独立桌面悬浮应用**，不是系统“添加小组件”列表内的 WidgetKit 组件。此实现可以持续刷新。

兼容目标：macOS 13 或更新版本、Apple Silicon。实测环境：本机 macOS 26.6.2 / arm64。未实测更旧系统或 Intel Mac。App 无第三方依赖，无管理员权限要求；未经过 Apple 开发者签名/公证，不保证其他 Mac 的 Gatekeeper 默认放行。无需关闭系统安全保护。

## 检测含义

| 层级 | 方法 | 局限 |
|---|---|---|
| 本机 | Network.framework 网络路径、默认路由、接口 IP | 并非 Wi-Fi 射频诊断；未读取 SSID/信号强度 |
| 网关 | 对默认网关发送 1 个 ICMP 探测 | 网关可能禁 ping；单独失败不等于断网 |
| DNS | `dscacheutil` 调用系统解析器 | 可能命中缓存/hosts，延迟含进程开销，不是纯 DNS 服务器 RTT |
| 外网 | 直连 1.1.1.1:443、8.8.8.8:443 的 TCP 建连 | 两个固定目标；不采用 HTTP 代理；企业策略、IPv6-only 或 VPN 可能限制 |
| 指定网站 | HTTP(S) HEAD，不发送 Cookie/保存的认证凭据 | 只验证 HTTP 响应，不代表登录、业务、文件传输等功能正常 |

网站设置支持 1–5 个 HTTP(S) URL。HTTP 4xx/5xx 是目标/认证/策略问题，不直接判断整体断网。405 标明“不支持 HEAD，业务未验证”。重定向只记录首跳，不自动把认证门户或跳转后的页面判为目标正常。HTTPS 仍使用系统证书验证，未绕过 TLS 校验。

监测请求本身会访问列出的探测目标；“日志不上传”并不意味着没有网络请求。公司禁止外部探测时请暂停或退出应用，并与 IT 确认可用目标。当前版本外网 TCP 两个目标固定，网站和 DNS 域名可以设置。

## 故障判定

- 实时结果每轮显示，连续 **3 轮同类异常**才确认、记录并可通知。
- 连续 **2 轮可达**才确认恢复。
- 网关不响应而下游成功：保留提示，不认定断网。
- TCP 直连失败而网站有响应：标记“直连探测受限”。
- DNS 失败而直接 TCP 成功：疑似解析问题，亦可能只是所选域名异常。
- 所有外部探测失败：给出出口/路径猜测与证据，不强行区分防火墙和真实链路故障。
- 单个网站异常：疑似服务端、TLS、认证、代理或该目标路径问题。
- 检测到系统代理开关/默认 VPN 接口时提示路径差异；透明代理及分流 VPN 未必能被识别。
- 暂停、休眠、换网、退出与更改目标会中断或重置证据，不把未观测时间算作已验证恢复。

趋势图展示两个成功 TCP 建连样本的平均值，缺失时断开曲线，两个目标均失败用叉号，不填充虚假的 0 ms。“失败 N/M”指至少一个 TCP 目标失败的轮数，非 ICMP 丢包率。高延迟阈值为 TCP 平均建连 >500 ms 或系统解析 >1000 ms；不是带宽测试。

## 记录与导出

数据目录：`~/Library/Application Support/NetworkLens/`。

- `settings.json`：设置。URL 查询参数如包含私密值会保存在此文件，建议使用不带凭据的检测地址。
- `samples.jsonl`：逐项结果。健康状态约每 30 秒落盘，异常逐轮落盘。
- `samples.previous.jsonl`：轮转备份。样本日志合计约 10 MB 上限。
- `incidents.json`：最近 200 个确认事件。

诊断导出包含当前会话最近 120 轮与最近 200 个事件；暂停、退出不会清除历史事件。历史日志可从设置中打开文件夹查看。报告含本机 IP、网关和探测主机，不含网站路径/查询参数，不包含通知凭据或浏览记录。发给 IT 前请检查内容。

## 通知、登录启动

通知和登录启动默认关闭，没有擅自配置系统登录项。

开启通知需要系统批准；登录启动可在设置中点击启用/停用（点击即生效，不随“取消”回滚）。建议先将 App 放到“应用程序”后再启用，以免移动文件导致登录项失效。系统可能要求在“通用 → 登录项”中批准。当前交付未实际开启通知或登录启动。

## 构建与验证

需要 Apple Command Line Tools 或 Xcode。终端进入本交付目录后运行 `./build.sh`。

源码：
- `Sources/Core.swift`：探测、配置校验与分层诊断。
- `Sources/App.swift`：桌面窗口、菜单栏、设置、日志、导出与生命周期。
- `Tests/SelfTests.swift`：判定、稳定性与记录测试。

诊断命令：
- `dist/NetworkLens.app/Contents/MacOS/NetworkLens --self-test`：确定性测试，使用独立临时目录，不改用户配置。
- `python3 Tests/test_http.py`：本地回环 HTTP 集成测试，包含 200/503/405/302/超时。
- `dist/NetworkLens.app/Contents/MacOS/NetworkLens --probe-once`：实际运行一轮默认网络探测并输出 JSON，不启动桌面窗口。
- `dist/NetworkLens.app/Contents/MacOS/NetworkLens --probe-url URL`：单次 HEAD 测试，2 秒超时。

界面与实测情况见 [验证记录](validation.zh-CN.md)。

## 卸载

在菜单栏退出应用。若曾开启登录启动，先在应用设置中停用。将 App 移到废纸篓即可；本地记录默认保留。如需一并移除，可自行将 `~/Library/Application Support/NetworkLens/` 文件夹移到废纸篓。
