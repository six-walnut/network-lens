# 验证记录

验证日期：2026-09-28；环境：macOS 26.6.2、Apple Silicon、Swift 6.2.4（Swift 5 语言模式）。

## 已实际完成

- 编译通过；最终构建日志无警告。
- `Info.plist` 格式验证通过。
- ad-hoc 签名 `codesign --verify --deep --strict` 通过。
- **39 项确定性测试**通过：分层诊断、ICMP 单独失败、防误报、DNS、HTTP 503/重定向、部分 TCP 失败、高延迟、三轮确认/两轮恢复、配置校验、IPv6 路由字段、代理字段、日志及事件持久化/重启读取/暂停中断。
- **5 项本地 HTTP 集成测试**通过：200、503、405、302、超时。2 秒超时场景约 2.03 秒返回。
- 本机实际探测：默认网关 ICMP 约 0.6–0.8 ms，系统域名解析约 10–16 ms；Apple、Baidu HEAD 返回 HTTP 200。数值随网络变化，仅是测试时结果。
- 两个外网直接 TCP 目标均超时；用系统 `nc -vz -G 3` 独立检查得到同样超时。组件显示“网站可达 · 直连探测受限”，未误报整体断网。
- GUI 真正启动；通过桌面辅助功能树和窗口截图检查结果展示、行布局、真实数据更新。
- 点击暂停后实际显示“检测已暂停”，按钮变为“继续检测”；已重新启动并恢复正常检测。
- 设置窗口真实打开，探测目标、刷新间隔、通知默认关闭、登录启动按钮均可见。

仓库不包含本机原始运行日志。可运行 README 中的测试命令复现，并查看 GitHub Actions 日志。未附带完整私有网络快照以避免无意分享局域网地址；用户可在应用内自行导出。
